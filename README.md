# leafi-site

Páginas de suporte e de privacidade do [Leafi](https://apps.apple.com/), o app
de prateleira de mangás, quadrinhos e livros.

Este repositório é público **só porque o GitHub Pages precisa disso** num plano
gratuito. O código do app continua no repositório privado.

- `index.html` — Support URL da ficha na App Store
- `privacy.html` — Privacy Policy URL
- `estilo.css` — paleta Sage do próprio app, clara e escura
- `icone.png` — ícone do app

## Publicar

Settings → Pages → Source: **Deploy from a branch**, branch `main`, pasta
`/ (root)`.

Depois de publicado, **abrir numa janela anônima** para confirmar que não pede
login. É a checagem que a Apple faz.

## Antes de publicar

Trocar `SEU-EMAIL@exemplo.com` pelo e-mail de contato real, nos dois arquivos.
Esse endereço fica público na App Store.
